# RX1-only Wi-Fi occupancy benchmark

Binary empty-versus-occupied classification using the first receiver's 13 precomputed CSI features from the [BUET ESP32-S3 project](https://github.com/Tahmid-Mahmud-Fahim/esp32-based-presence-and-motion-detection-using-wifi-csi), pinned to commit `adc39ac0c05b493e3ecd4c75447b528d120d6d1e`. The source dataset uses one transmitter and two receivers in one room, but this benchmark uses only RX1 features. The source documentation does not establish participant consent. No tracking or location prediction is performed.

Run `python3 wifi_benchmark/download_data.py` to download and SHA-256 verify the source feature tables, then run `OPENBLAS_NUM_THREADS=1 python3 wifi_benchmark/benchmark.py` with Python 3 and NumPy. The source paths are `phase1/data/processed/{train_features.csv,val_features.csv,test_features.csv,metadata.json}`. Data is excluded from version control; check source reuse terms before redistribution. The source supplies the splits; train, validation, and test session IDs do not overlap, and no selected 13-feature vector matches exactly across any pair of splits. Exact duplicate detection does not rule out near-duplicates or shared acquisition conditions.

The benchmark standardizes using training data, fits a fixed L2 logistic regression, and exports `model.json` (ordered features, means, standard deviations, coefficients, intercept, and threshold) and aggregate `results.json`. The source metadata says its empty-room baseline was constructed from training empty sessions; this claim was not independently recomputed. Baseline-derived features require the source's preprocessing and empty-room reference profile: the exported weights alone do not support live inference from raw ESP32 data, and no live or different-device validation is claimed.

On the held-out test split, 1,089 overlapping windows from nine recordings yielded TN 242, FP 0, FN 47, TP 800: balanced accuracy 97.23%, occupied recall 94.45%, and false-positive rate 0%. Averaging probabilities per recording classified 9 of 9 sessions correctly, but just two were empty. Windows overlap and are not independent. Data comes from one room and one acquisition setup; these figures do not establish accuracy elsewhere or in live use.

For a control, 50 models were retrained after shuffling labels across entire training sessions while keeping test labels unchanged. Their mean test window balanced accuracy was 44.58%, with a maximum of 91.38%; none matched the actual result. The mean session-balanced accuracy was 44.43%, and the maximum was 100% because the test has only nine sessions. This is a small, fixed-seed sanity check, not a generalization guarantee or formal significance claim.
